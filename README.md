# Blinkit-Landing-Page

A frontend clone inspired by the Blinkit homepage.  
This project focuses on clean layout structure, responsive design, and modern UI styling using only HTML and CSS.

---

## 🚀 Features

- Fully responsive landing page  
- Clean and simple HTML structure  
- Modern UI built with pure CSS  
- Separate stylesheet for responsiveness  
- Organized project folder for easy editing

---

## 📁 Project Structure

blinki-landing-page/
│── blinkit.html
│── blinkit.css
│── media.css
│── assets/
└── images/


- **blinkit.html** — main landing page file  
- **blinkit.css** — primary styles for layout and components  
- **media.css** — responsive styles for mobile and tablet breakpoints  
- **assets/images/** — image files used in the project

---

## 📱 Responsive Design

The layout adapts to:

- Mobile screens  
- Desktop monitors  

Responsiveness is handled using `media.css` to keep the main styles clean and organized.

---

## 🎯 Purpose of the Project

This project was created for learning and practice:

- Understanding how real websites structure layouts looks like
- Improving HTML & CSS skills  
- Practicing responsive design  
- Cloning modern UI for portfolio development
